## Important state and data flow

One sender taps Pay → mobile posts profile IDs and amount → backend checks the current receiver score and balance → backend writes an SQLite transaction. For ESCROW, the backend calls the ethers bridge, which sends a local-chain transaction from the oracle account and returns its hash/events. The backend stores that receipt and broadcasts an SSE state update. Later dashboard score changes use an authenticated REST route, then the oracle updates the contract; the backend applies the same transition to SQLite and publishes the result. The clients display the backend snapshot, including the blockchain hash when one exists.
